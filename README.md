One line (103 characters) roasting my own agent for the make.fun bounty
[Roast Your Own Agent](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54).

> My agent apologized for the mistake, then made the exact same mistake again — this time with citations.

The apology is the setup; the repeat offence is the punchline — and the
citations are the agent's favourite way of being confidently wrong.

`main.ts` writes the line to `/output/entry.txt` and verifies it against the
gate (1–140 characters, single line).

Run it with `MAKEFUN_OUTPUT_DIR` set, e.g. `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts`.
